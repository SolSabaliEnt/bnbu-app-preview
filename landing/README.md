# BNBU landing images — replacement instructions

Current V2.1 preview uses licensed Unsplash stock photography. These are **illustrative models, not BNBU members, staff, customers, or endorsers**.

## Replace images
1. Add approved images to this directory (`public/landing/`), ideally at least 1200px wide.
2. Open `src/app/config/landingImages.ts`.
3. Update the relevant `src` value to point at your file (e.g. `'/landing/hero-community.jpg'`).
4. Keep or improve the descriptive `alt` text.
5. Push the changes to the V2.1 design review branch to refresh the review build.

| Slot | Recommended replacement filename | Suggested subject |
| --- | --- | --- |
| Hero | `hero-community.jpg` | Two or three Black entrepreneurs collaborating |
| Mission | `mission-founder.jpg` | A founder working, candid and confident |
| Experience | `experience-workshop.jpg` | Working session or small group discussion |
| Closing | `closing-community.jpg` | Community, collaboration, or workshop moment |

*Avoid publishing customer or member photos without consent and rights clearance.* When real approved testimonials are available, they can be added to a separate verified proof section. The prior prototype's numerical claims and fictional-looking testimonials are not reused here.

**Approved copy rule:** The V2.1 page retains the original landing page's hero, mission, hub descriptions, membership tier names/taglines, and key calls to action. Do not change these without reviewing with the brand copywriter. Membership pricing and offerings remain prototype-only pending approval.
